About splitting

Each picture shows the frame the way it looks when the GIF plays, not just the part of it the GIF stores. PNG keeps every pixel and any transparency exactly. JPG files are smaller but slightly blurred, and transparent areas become white.

Can I put the frames back together?

Yes: edit the pictures in any image editor, then drop them on Images to GIF. The file names are numbered, so Sort by file name puts them back in order.
