Resizing tips

Making a GIF smaller in size is the most effective way to make the file smaller: half the width and height is usually around a third of the bytes. Enlarging a GIF can't add detail, but it can make pixel art or small stickers bigger without blurring too much.

Will it lose quality?

Resizing creates new in-between colours, so the GIF has to be re-encoded with a fresh palette. The default quality of 90 keeps it very close to a perfect resize. Use Compress afterwards if you want a smaller file.
